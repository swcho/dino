# 지식 증류의 기본 수식 — 고등학교 수학으로 따라가기

## 0. 한 줄 요약

**선생님(teacher) 신경망이 낸 답안을 학생(student) 신경망이 흉내내도록 훈련시키는 것.** 단, 여기서 "답안"은 정답 하나가 아니라 **확률분포** 전체다. 그래서 두 개의 확률분포를 비교하는 방법이 필요하고, 그 도구가 softmax와 cross-entropy다.

---

## 1. 등장인물 정리

신경망은 결국 **함수**다. 입력을 넣으면 숫자들이 나온다.

$$g_{\theta}: \; x \;\longmapsto\; \big(g_\theta(x)^{(1)},\, g_\theta(x)^{(2)},\, \dots,\, g_\theta(x)^{(K)}\big)$$

- $x$: 입력 (여기서는 이미지 한 장)
- $\theta$ (세타): 그 함수의 **계수들**. 고교 함수 $f(x) = ax^2 + bx + c$ 에서 $a, b, c$ 에 해당한다고 생각하면 된다. 다만 개수가 수천만 개일 뿐이다. "학습한다"는 건 이 $\theta$ 를 바꾼다는 뜻.
- 출력은 $K$ 개의 실수를 나열한 것 — 즉 **$K$ 차원 벡터**다. 고교에서 배운 평면벡터 $(a, b)$, 공간벡터 $(a,b,c)$ 를 성분 개수만 $K$ 개로 늘린 것.

지식 증류에는 이런 함수가 **두 개** 등장한다.

- **student** $g_{\theta_s}$ — 우리가 훈련시킬 대상. 아래 첨자 $s$ = student.
- **teacher** $g_{\theta_t}$ — 목표를 알려주는 쪽. 아래 첨자 $t$ = teacher.

같은 이미지 $x$ 를 두 함수에 넣으면 각각 $K$ 차원 벡터가 나온다. 이 벡터를 확률분포로 바꾼 것이 $P_s(x)$, $P_t(x)$ 다.

---

## 2. $K$ 차원 벡터를 확률분포로 — softmax

### 2-1. 문제 상황

신경망 출력은 그냥 실수다. 예를 들어 $K = 3$ 일 때

$$g_\theta(x) = (2.0,\ 1.0,\ 0.1)$$

이런 게 나온다. 음수가 나올 수도 있고, 다 더해도 1이 아니다. **확률분포가 되려면 두 조건**을 만족해야 한다(고교 확률과 통계의 확률분포 정의 그대로).

1. 모든 값이 0 이상 (여기선 0보다 큼)
2. 전부 더하면 1

### 2-2. 조건 1 해결 — 지수함수는 항상 양수

고교에서 배운 사실: 임의의 실수 $u$ 에 대해
$$e^u > 0$$
지수함수 $y = e^u$ 의 그래프는 $u$ 축 위로만 지나간다. 즉 **어떤 실수를 넣어도 결과는 양수**. 그러니 음수 걱정 없이 모든 성분에 $\exp$ 를 씌우면 된다.

$$(2.0,\ 1.0,\ 0.1) \;\xrightarrow{\ \exp\ }\; (e^{2.0},\ e^{1.0},\ e^{0.1}) = (7.389,\ 2.718,\ 1.105)$$

### 2-3. 조건 2 해결 — 합으로 나눈다 (정규화)

이제 다 더하면
$$7.389 + 2.718 + 1.105 = 11.212$$
이다. 각 항을 **이 합으로 나누면** 당연히 총합이 1이 된다.

$$\left(\frac{7.389}{11.212},\ \frac{2.718}{11.212},\ \frac{1.105}{11.212}\right) = (0.659,\ 0.242,\ 0.099)$$

확인: $0.659 + 0.242 + 0.099 = 1.000$. 모든 값이 양수. **확률분포 완성!**

이 두 단계(지수 씌우기 → 합으로 나누기)를 합친 것이 **softmax**이고, 논문 식 (1)이 정확히 이것이다.

$$P_s(x)^{(i)} = \frac{\exp\big(g_{\theta_s}(x)^{(i)}/\tau_s\big)}{\sum_{k=1}^{K}\exp\big(g_{\theta_s}(x)^{(k)}/\tau_s\big)}$$

분자 = $i$ 번째 성분에 지수 씌운 것, 분모 = 전부에 지수 씌워 더한 것. **분모가 바로 "합으로 나눈다"의 그 합**이다. 시그마 $\sum_{k=1}^{K}$ 는 고교의 수열 합 기호와 같은 뜻이다.

> 왜 그냥 각 값을 합으로 나누지 않고 굳이 $\exp$ 를 씌우나? 음수가 섞이면 "합으로 나누기"만으로는 음수 확률이 생기고, 합이 0이 되어 분모가 터질 수도 있기 때문이다. $\exp$ 는 이 두 문제를 한 번에 없앤다. 덤으로 큰 값과 작은 값의 차이를 벌려 준다.

### 2-4. 온도 $\tau$ (타우) — 분포를 뾰족하게/평평하게

식 (1)에는 $\tau_s > 0$ 로 나누는 부분이 있다. 값이 나오기 전에 **모든 성분을 $\tau$ 로 나누는 것**뿐인데 효과가 크다. 같은 $(2.0, 1.0, 0.1)$ 로 실험해 보자.

| $\tau$ | $\tau$ 로 나눈 값 | softmax 결과 | 모양 |
|---|---|---|---|
| $\tau = 2$ | $(1.0,\ 0.5,\ 0.05)$ | $(0.502,\ 0.304,\ 0.194)$ | 평평함 |
| $\tau = 1$ | $(2.0,\ 1.0,\ 0.1)$ | $(0.659,\ 0.242,\ 0.099)$ | 보통 |
| $\tau = 0.5$ | $(4.0,\ 2.0,\ 0.2)$ | $(0.864,\ 0.117,\ 0.019)$ | 뾰족함 |

$\tau$ 를 **작게** 하면 나눈 값들의 차이가 벌어지고, 지수함수가 그 차이를 더 크게 증폭해서 1등이 확률을 독식한다 → **sharpening(뾰족하게)**. 반대로 $\tau$ 를 크게 하면 성분들이 서로 가까워져 균등분포에 가까워진다. 논문이 "$\tau$ 가 출력 분포의 sharpness를 제어한다"고 한 게 이 뜻이다. 극단적으로 $\tau \to 0$ 이면 최댓값 자리만 1이고 나머지는 0인 분포가 된다.

DINO에서는 student는 $\tau_s = 0.1$, teacher는 $\tau_t$ 를 0.04~0.07로 **더 작게** 쓴다. 즉 teacher가 더 확신에 찬(뾰족한) 목표를 준다.

## 3. 두 확률분포를 어떻게 "비교"하나 — cross-entropy

이제 student 분포 $P_s$ 와 teacher 분포 $P_t$ 가 둘 다 $K$ 차원 확률분포다. "student가 teacher를 잘 따라간다"를 **하나의 숫자**로 재야 학습(=그 숫자를 줄이기)이 가능하다.

논문 식 (2)의 정답:

$$\min_{\theta_s} H\big(P_t(x), P_s(x)\big), \qquad H(P_t, P_s) = -\sum_{i=1}^{K} P_t^{(i)} \log P_s^{(i)}$$

### 3-1. $-\log$ 는 "놀람의 정도"

먼저 $-\log p$ 라는 양을 보자 ($0 < p \le 1$, 로그는 자연로그).

| $p$ (그 일이 일어날 확률) | $-\ln p$ |
|---|---|
| $1$ | $0$ |
| $0.7$ | $0.357$ |
| $0.2$ | $1.609$ |
| $0.01$ | $4.605$ |
| $\to 0$ | $\to \infty$ |

로그함수의 그래프를 떠올리면 바로 보인다. **확률이 1이면 0, 확률이 작아질수록 커지고, 0에 가까우면 무한대로 발산한다.** 그래서 $-\log p$ 를 "확률 $p$ 짜리 사건이 실제로 일어났을 때 느끼는 놀람(정보량)"으로 읽는다. 당연한 일엔 안 놀라고, 희박한 일엔 크게 놀란다.

### 3-2. cross-entropy = "놀람의 기댓값"

고교 확률과 통계의 **기댓값** 정의를 그대로 쓰자. 확률변수 $X$ 가 값 $x_i$ 를 확률 $p_i$ 로 가질 때 $E[X] = \sum_i p_i x_i$.

여기서 "실제로 일어나는 확률"은 teacher의 $P_t$, "놀람의 크기"는 student 예측으로 잰 $-\log P_s^{(i)}$ 다. 그 기댓값이

$$H(P_t, P_s) = \sum_{i=1}^{K} P_t^{(i)} \cdot \big(-\log P_s^{(i)}\big) = -\sum_{i=1}^{K} P_t^{(i)} \log P_s^{(i)}$$

즉 **"teacher가 실제로 잘 일어난다고 말하는 곳에서 student가 얼마나 놀라는가"의 평균**이다. student가 teacher와 같은 곳에 확률을 몰아 줬다면 놀랄 일이 없으니 작고, 엉뚱한 곳에 몰아 줬다면 크다.

### 3-3. 숫자로 확인

teacher 분포를 $P_t = (0.7,\ 0.2,\ 0.1)$ 로 고정하고 세 student를 비교해 보자.

**(가) 비슷하게 맞춘 student** $P_s = (0.659,\ 0.242,\ 0.099)$

$$H = -\big(0.7\ln 0.659 + 0.2\ln 0.242 + 0.1\ln 0.099\big)$$
$$= -\big(0.7(-0.417) + 0.2(-1.419) + 0.1(-2.317)\big) = 0.292 + 0.284 + 0.232 = \boxed{0.808}$$

**(나) 아무것도 모르는 student** $P_s = (1/3,\ 1/3,\ 1/3)$

$$H = -\sum_i P_t^{(i)}\ln\tfrac13 = -\ln\tfrac13 \cdot \underbrace{\textstyle\sum_i P_t^{(i)}}_{=1} = \ln 3 = \boxed{1.099}$$

(일반적으로 균등분포를 내면 손실이 $\ln K$ 가 된다. 논문 부록에서 "붕괴하면 손실이 $\ln(K)$ 로 수렴한다"고 말하는 그 값이다.)

**(다) 정반대로 찍은 student** $P_s = (0.1,\ 0.2,\ 0.7)$

$$H = -\big(0.7\ln 0.1 + 0.2\ln 0.2 + 0.1\ln 0.7\big) = 1.612 + 0.322 + 0.036 = \boxed{1.969}$$

정리: (가) $0.808 <$ (나) $1.099 <$ (다) $1.969$. **teacher와 닮을수록 값이 작다.** 그래서 이 값을 최소화하면 자동으로 student가 teacher를 흉내내게 된다.

### 3-4. 그런데 왜 0이 아니라 0.808이 최솟값 근처인가? — 여기서 KL이 나온다

(가)에서 완벽히 일치시키면 어떻게 될까? $P_s = P_t = (0.7, 0.2, 0.1)$ 을 넣어 보면

$$H(P_t, P_t) = -\big(0.7\ln 0.7 + 0.2\ln 0.2 + 0.1\ln 0.1\big) = 0.250 + 0.322 + 0.230 = 0.802$$

0이 아니다. 이 **0.802가 바닥값**이고, teacher 분포 자체가 원래 갖고 있는 불확실성이다. 이걸 $P_t$ 의 **엔트로피** $h(P_t)$ 라고 부른다 (놀람의 기댓값을 teacher 자신으로 잰 것).

그러면 실제 손실에서 이 바닥값을 빼 준 나머지가 "얼마나 어긋났는가"의 순수한 몫이다.

$$D_{KL}(P_t \,\|\, P_s) \;=\; H(P_t, P_s) - h(P_t)$$

이것이 대학에서 배우는 **KL divergence**인데, 고교 개념만으로 이렇게 읽으면 된다: **"student로 쟀을 때의 평균 놀람 − 원래 피할 수 없는 평균 놀람"**. 위 예에서

- (가): $0.808 - 0.802 = 0.006$ (거의 일치)
- (나): $1.099 - 0.802 = 0.297$
- (다): $1.969 - 0.802 = 1.167$

성질 두 가지만 기억하면 충분하다.

1. **항상 $D_{KL} \ge 0$**
2. **$D_{KL} = 0 \iff P_s = P_t$** (완전히 같을 때만 0)

이 두 성질 덕분에 $D_{KL}$ 은 "분포 사이의 거리"처럼 행동한다. 그리고 $h(P_t)$ 는 $\theta_s$ 와 무관한 상수이므로,

$$\underbrace{H(P_t, P_s)}_{\text{실제로 최소화하는 것}} = \underbrace{h(P_t)}_{\text{상수}} + \underbrace{D_{KL}(P_t\|P_s)}_{\text{줄일 수 있는 부분}}$$

**cross-entropy를 최소화하는 것 = 거리 $D_{KL}$ 을 최소화하는 것**이다. 논문 부록의 식 (5)가 바로 이 분해다.

> 엄밀히 말해 $D_{KL}$ 은 진짜 거리는 아니다. $D_{KL}(P_t\|P_s) \ne D_{KL}(P_s\|P_t)$ 로 **대칭이 아니기** 때문이다(고교의 두 점 사이 거리는 대칭이다). 그래서 "거리처럼 작동한다"고만 말한다. 순서가 중요해서, 식 (2)에서 앞자리가 teacher, 뒷자리가 student인 것에도 의미가 있다.

## 4. 최소화하는 변수는 오직 $\theta_s$

식 (2)의 $\min_{\theta_s}$ 를 놓치면 안 된다. 고교 미적분에서 "함수의 최솟값 찾기 = 미분해서 0이 되는 지점" 이었듯, 여기서도 손실 $H$ 를 $\theta_s$ 로 미분해 그 반대 방향으로 조금씩 $\theta_s$ 를 움직인다(경사하강법).

**teacher는 건드리지 않는다.** 논문 표현으로 "given a fixed teacher", 그림에서는 `sg`(stop-gradient) 표시, 코드에서는 `t.detach()`. 목표(과녁)가 자기도 같이 도망가면 학습이 안 되기 때문이다.

## 5. 여기까지가 "기본 설정", DINO의 반전은 그다음

지금까지 식 (1), (2)는 **고전적인 지식 증류**(Hinton 2015) 그대로다. 원래는

- teacher = 미리 잘 학습된 **큰** 모델, student = **작은** 모델 → 목적은 모델 압축
- $K$ = **분류할 클래스의 개수** (예: 개/고양이/자동차라면 $K=3$, ImageNet이면 $K=1000$)

DINO는 여기서 세 가지를 바꾼다.

1. **정답 레이블이 하나도 없다.** teacher도 정답을 모른다. 대신 같은 사진의 서로 다른 조각(crop) 두 개를 각각 넣고 "두 분포가 같아야 한다"고 요구한다.
2. **teacher를 student로부터 만든다.** teacher 파라미터는 student 파라미터의 **이동평균**이다.
   $$\theta_t \leftarrow \lambda\,\theta_t + (1-\lambda)\,\theta_s \qquad (\lambda \approx 0.996 \to 1)$$
   $\lambda$ 가 1에 가까우므로 teacher는 student를 아주 천천히 따라간다 = student의 과거 모습들의 평균. 흔들리는 student보다 안정적이라 좋은 과녁이 된다. 그래서 **자기 증류(self-distillation)**.
3. **$K$ 는 클래스 수가 아니다.** 레이블이 없으니 각 차원에 "개", "고양이" 같은 의미가 없다. 그냥 **임의로 정한 출력 차원**일 뿐이고, DINO 기본값은 놀랍게도 $K = 65536$ 이다. "$i$ 번째 칸이 무엇을 뜻하는지"는 아무도 지정하지 않고, 학습 과정에서 알아서 정해진다.

## 6. 핵심 정리

| 물음 | 답 |
|---|---|
| 등장하는 두 함수는? | student $g_{\theta_s}$, teacher $g_{\theta_t}$ |
| 출력은? | 같은 입력 $x$ 에 대한 $K$ 차원 확률분포 $P_s$, $P_t$ |
| 왜 확률분포가 되나? | $\exp$ 가 항상 양수 + 전체 합으로 나눠 총합 1 → softmax (식 (1)) |
| $\tau$ 의 역할은? | 작을수록 뾰족한 분포, 클수록 평평한 분포 |
| 무엇을 최소화하나? | cross-entropy $H(P_t, P_s) = -\sum_i P_t^{(i)}\log P_s^{(i)}$ (식 (2)) |
| 왜 그게 "닮게" 만드나? | $H = h(P_t) + D_{KL}(P_t\|P_s)$ 이고 $D_{KL} \ge 0$, 등호는 $P_s = P_t$ 일 때뿐 |
| 무엇을 학습하나? | $\theta_s$ 뿐. teacher는 고정(stop-gradient) |
