# 엔트로피 $h(p) = -\sum_i p_i \log p_i$ — 고교 수학에서 출발하기

## 0. 한 줄 요약

확률분포 $p = (p_1, p_2, \dots, p_K)$가 있을 때

$$h(p) = -\sum_{i=1}^{K} p_i \log p_i$$

를 $p$의 **엔트로피(entropy)** 라 한다. "이 분포가 얼마나 퍼져 있는가 / 얼마나 예측하기 어려운가"를 **숫자 하나**로 요약한 값이다.

---

## 1. 먼저 "확률분포"부터 정리

고교 확률과 통계에서 배운 이산확률분포 그대로다. 사건이 $K$가지 있고, 각각의 확률이 $p_i$일 때

$$p_i \ge 0, \qquad \sum_{i=1}^{K} p_i = 1$$

예를 들어 $K=4$일 때

| 분포 | $p$ | 느낌 |
|---|---|---|
| 확정 | $(1, 0, 0, 0)$ | 무조건 1번. 놀랄 일 없음 |
| 치우침 | $(0.7, 0.2, 0.05, 0.05)$ | 대체로 1번 |
| 균등 | $(0.25, 0.25, 0.25, 0.25)$ | 뭐가 나올지 전혀 모름 |

직관적으로 "퍼진 정도"는 확정 < 치우침 < 균등 순이다. 이 순서를 **하나의 실수**로 매기고 싶다. 그 답이 엔트로피다.

---

## 2. 왜 하필 $-\log p_i$ 인가 — "놀람의 양"

사건 $i$가 실제로 일어났을 때 우리가 느끼는 **놀람(surprise)** 을 수식으로 정의해 보자. 놀람 함수를 $s(p_i)$라 하고, 상식적으로 이런 성질을 요구한다.

1. **확률이 클수록 덜 놀란다**: $p_i$가 커지면 $s(p_i)$는 작아진다 (감소함수).
2. **확실한 일에는 안 놀란다**: $p_i = 1$ 이면 $s(1) = 0$.
3. **독립사건은 놀람이 더해진다**: 확률 $p$인 사건과 확률 $q$인 사건이 독립으로 둘 다 일어나면 확률은 $pq$인데, 놀람은 두 배가 아니라 각각의 **합**이어야 자연스럽다. 즉

$$s(pq) = s(p) + s(q)$$

3번이 결정적이다. 고교 지수·로그 단원에서 배운 로그의 성질

$$\log(pq) = \log p + \log q$$

가 정확히 "곱을 합으로 바꾸는" 유일한 성질이다. 여기에 1번(감소)과 2번($s(1)=0$, 로그는 $\log 1 = 0$)까지 맞추면

$$s(p) = -\log p$$

밖에 남지 않는다. ($0 < p \le 1$이면 $\log p \le 0$이므로 $-\log p \ge 0$, 놀람은 항상 0 이상이다.)

> **로그의 밑은?** 밑을 $e$로 쓰면 단위가 **nat**, 밑을 2로 쓰면 **bit**다. 밑을 바꿔도 $\log_2 x = \ln x / \ln 2$라서 전체가 상수배로만 달라진다 — 분포끼리 비교하는 데는 영향이 없다. 딥러닝 코드에서는 거의 항상 자연로그($\ln$)를 쓴다.

---

## 3. 엔트로피 = 놀람의 기댓값

고교 확률과 통계의 **기댓값** 정의를 떠올리자. 확률변수 $X$가 값 $x_i$를 확률 $p_i$로 가질 때

$$E[X] = \sum_i p_i \, x_i$$

이제 "놀람"이라는 확률변수 $S$를 정의한다. 사건 $i$가 일어나면 $S = -\log p_i$ 라는 값을 갖는 확률변수다. 그 기댓값이 바로 엔트로피다.

$$h(p) = E[\,-\log p_i\,] = \sum_i p_i \cdot (-\log p_i) = -\sum_i p_i \log p_i$$

즉 **엔트로피는 "이 분포에서 한 번 뽑았을 때 평균적으로 얼마나 놀랄까"** 이다. 앞의 마이너스 부호는 $\log p_i \le 0$을 뒤집어 값을 0 이상으로 만들기 위한 것이다.

> **$p_i = 0$일 때는?** 항이 $0 \cdot \log 0$이 되어 정의가 안 되는 듯하지만, 미적분의 극한으로
> $$\lim_{p \to 0^+} p \log p = 0$$
> 이므로 (분자 $\log p \to -\infty$, 분모 $1/p \to +\infty$ 꼴에 로피탈을 쓰면 $\frac{1/p}{-1/p^2} = -p \to 0$) 그냥 **0으로 취급**한다. 실제 코드에서 `p.clamp_min(1e-12).log()` 같이 아주 작은 값으로 잘라 주는 이유가 이것이다.

## 4. 값을 직접 계산해 보기 ($K = 4$, 자연로그)

**(a) 확정 분포 $p = (1,0,0,0)$**

$$h = -(1 \cdot \log 1) - 0 - 0 - 0 = 0$$

놀랄 일이 전혀 없다. **엔트로피의 최솟값은 0**이고, 이는 확률이 한 칸에 몰린 경우(원-핫)에만 일어난다.

**(b) 균등 분포 $p = (\tfrac14, \tfrac14, \tfrac14, \tfrac14)$**

$$h = -\sum_{i=1}^{4} \frac14 \log \frac14 = -\log\frac14 = \log 4 \approx 1.386$$

**(c) 치우친 분포 $p = (0.7, 0.2, 0.05, 0.05)$**

$$h = -(0.7\log 0.7 + 0.2\log 0.2 + 2 \times 0.05\log 0.05) \approx 0.2497 + 0.3219 + 0.2996 = 0.8711$$

$0 < 0.8711 < 1.3863$ — 예상대로 확정과 균등 사이다.

## 5. 최댓값은 왜 $\log K$ 인가

**주장:** $K$개 칸의 분포 중 엔트로피가 가장 큰 것은 균등분포이고, 그 값은 $\log K$다.

고교 수준에서 볼 수 있는 이유는 **로그 함수가 위로 볼록(concave)** 하다는 사실이다. $y = \log x$의 이계도함수는

$$\frac{d^2}{dx^2}\log x = -\frac{1}{x^2} < 0$$

이므로 $\log$는 위로 볼록이다. 위로 볼록한 함수에 대해서는 **옌센(Jensen) 부등식**

$$\sum_i p_i \log(a_i) \le \log\!\left(\sum_i p_i a_i\right)$$

이 성립한다 (고교식으로는 "가중평균의 로그 $\ge$ 로그의 가중평균", 즉 곡선이 현보다 위에 있다는 것). 여기에 $a_i = 1/p_i$ 를 넣으면

$$h(p) = \sum_i p_i \log \frac{1}{p_i} \le \log\!\left(\sum_i p_i \cdot \frac{1}{p_i}\right) = \log K$$

등호는 모든 $1/p_i$가 같을 때, 즉 $p_i = 1/K$ (균등분포)일 때만 성립한다. 정리하면

$$\boxed{\,0 \le h(p) \le \log K\,}$$

- $h = 0$: 완전히 뾰족함(한 칸에 몰빵, 원-핫)
- $h = \log K$: 완전히 퍼짐(균등)

$K = 8$이면 $\log 8 \approx 2.079$, $K = 32$면 $\log 32 \approx 3.466$이다. 이 두 숫자는 자료의 노트북에 계속 등장한다.

## 6. 왜 "분산"이 아니라 엔트로피인가

"퍼진 정도"라면 고교에서 배운 **분산** $V(X) = E[(X-m)^2]$도 있다. 그런데 분산은 값 $x_i$들 사이의 **거리**를 쓴다. 분류 문제의 클래스 번호(1번 클래스, 2번 클래스, …)는 순서나 거리에 의미가 없다 — "고양이"와 "개"가 3만큼 떨어졌다는 말은 뜻이 없다.

엔트로피는 $p_i$만 쓰고 $i$가 무엇인지는 전혀 보지 않는다. 그래서 **라벨을 뒤섞어도 값이 변하지 않는다.** 범주형 분포의 퍼짐을 재는 데 알맞은 척도인 이유다.

## 7. 이 카드가 왜 DINO 자료에 나오는가

자료의 노트북(`dino_collapse_cross_entropy.py`)에서 엔트로피는 이렇게 쓰인다.

**(1) 온도(temperature)로 엔트로피를 조절한다.** 신경망이 뱉은 실수 벡터(로짓) $z$를 확률로 바꿀 때 softmax를 쓰는데,

$$p_i = \frac{\exp(z_i/\tau)}{\sum_j \exp(z_j/\tau)}$$

- $\tau$가 작으면 → 큰 로짓이 더 강조 → 뾰족 → $h(p) \downarrow$ (DINO의 **sharpening**, teacher는 $\tau = 0.04$)
- $\tau$가 크면 → 차이가 뭉개짐 → 평평 → $h(p) \uparrow$

**(2) 교차엔트로피를 두 조각으로 쪼갤 때 엔트로피가 한 조각이다.**

$$H(q,p) = -\sum_i q_i \log p_i = \underbrace{h(q)}_{\text{target 분포의 엔트로피}} + \underbrace{D_{KL}(q\|p)}_{\text{두 분포가 다른 정도}}$$

DINO는 $H(q,p)$를 줄이도록 학습하는데, 위 식을 보면 줄이는 길이 두 개다. $p \to q$ (원하는 것)와 $h(q) \downarrow$ (target 분포 자체가 뾰족해지는 것). 후자가 **붕괴(collapse)** 의 통로다.

**(3) 붕괴 진단 지표로 쓰인다.**

- `h_each` = 점 하나하나의 분포 엔트로피 평균 → "확신하는가"
- `h_mean` = 전체 점의 **평균 분포**의 엔트로피 → "출력 차원을 골고루 쓰는가"

둘 다 0에 가까우면 원-핫 붕괴, 둘 다 $\log K$면 균등 붕괴, `h_each` 낮고 `h_mean` 높으면 건강하다. 정의 하나가 진단 도구 두 개로 갈라지는 셈이다.

## 8. 기억할 것

| 항목 | 내용 |
|---|---|
| 정의 | $h(p) = -\sum_i p_i \log p_i$ |
| 정체 | 놀람 $-\log p_i$의 **기댓값** |
| 범위 | $0 \le h(p) \le \log K$ |
| 최소 | 원-핫 분포에서 $h = 0$ |
| 최대 | 균등분포에서 $h = \log K$ |
| 규약 | $0\log 0 = 0$ (극한값) |
| 단위 | 밑 $e$ → nat, 밑 2 → bit |
