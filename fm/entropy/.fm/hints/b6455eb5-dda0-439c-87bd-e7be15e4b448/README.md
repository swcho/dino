# centering의 메커니즘 — 왜 "평균 빼기"가 원-핫 붕괴를 막는가

> **한 줄 요약**: 로짓에서 배치 평균의 EMA $c$ 를 빼는 것은, 확률 공간에서 각 차원에
> $e^{-c_i/\tau_t}$ 라는 **곱셈적 페널티**를 매기는 일이다. 자주 크게 나오는 차원일수록 $c_i$ 가 커지고
> 페널티가 지수적으로 세지므로, 승자독식(양의 피드백)을 정확히 상쇄하는 **음의 피드백 루프**가 된다.
> 단, softmax는 시프트 불변이므로 실제로 작동하는 것은 center의 **차원 간 편차** $\tilde c = c - \bar c\mathbf 1$ 뿐이고,
> 균등 붕괴 상태에서는 그 편차가 0으로 죽어 centering이 항등연산이 된다 — 이것이 사각지대다.

코드 한 줄로는 이게 전부다 ([`main_dino.py:388`](../../../../../main_dino.py#L388), `DINOLoss.forward`):

```python
teacher_out = F.softmax((teacher_output - self.center) / temp, dim=-1)
```

그리고 center의 갱신 (식 (4), [`main_dino.py:405-415`](../../../../../main_dino.py#L405-L415)):

$$c \leftarrow m\,c + (1-m)\,\frac{1}{B}\sum_{i=1}^{B} g_{\theta_t}(x_i), \qquad m = \texttt{center\_momentum} = 0.9$$

`update_center`는 `@torch.no_grad()`이고 `center`는 `register_buffer`다. **centering은 loss 항이 아니라
teacher 타깃에 걸리는 바이어스 보정**이다. 학습되는 파라미터가 아니라 관측된 통계로 굴러간다.
(분산 환경에서 `dist.all_reduce`로 배치 평균을 어떻게 모으는지는 형제 카드가 다룬다.)

이 문서의 모든 수치는 같은 폴더의 [`expy.py`](./expy.py) 실행 결과다 (`K=16`, `B=256`, $\tau_t=0.04$).

## 1. 로짓의 뺄셈 = 확률의 곱셈적 재가중

센터링 전의 teacher 분포를 $p = \mathrm{softmax}(z/\tau_t)$ 라 하자. 센터링 후는

$$
\mathrm{softmax}\!\left(\frac{z - c}{\tau_t}\right)_i
= \frac{e^{(z_i - c_i)/\tau_t}}{\sum_j e^{(z_j-c_j)/\tau_t}}
= \frac{e^{z_i/\tau_t}\,e^{-c_i/\tau_t}}{\sum_j e^{z_j/\tau_t}\,e^{-c_j/\tau_t}}
$$

분자·분모를 $\sum_k e^{z_k/\tau_t}$ 로 나누면 $p$ 가 드러난다:

$$
\boxed{\;\mathrm{softmax}\!\left(\frac{z-c}{\tau_t}\right)_i = \frac{p_i\, e^{-c_i/\tau_t}}{\sum_j p_j\, e^{-c_j/\tau_t}}\;}
$$

**로짓 공간의 덧셈은 확률 공간의 곱셈이다.** center를 빼는 것은 각 차원 $i$ 에 가중치
$w_i = e^{-c_i/\tau_t}$ 를 곱한 뒤 다시 정규화하는 것과 완전히 같다.

`expy.py` (b)에서 $\tau=1$, $z=(4,0,0,0)$, $c=(3,0,0,0)$ 으로 검증했다:

| | dim 0 | dim 1–3 |
|---|---|---|
| $p$ (센터링 전) | 0.947915 | 0.017362 |
| $w = e^{-c/\tau}$ | 0.049787 | 1.0 |
| $pw$ 정규화 | **0.475367** | 0.174878 |
| `softmax((z-c)/τ)` 직접 계산 | **0.475367** | 0.174878 |

두 값이 같다 (`torch.allclose → True`).

### 억제는 지수적이고, 온도가 그것을 증폭한다

페널티는 $c_i$ 에 대해 **지수적**이다. $\tau_t = 0.04$ 이므로 center의 아주 작은 차이도 크게 증폭된다:

| $c_i$ 가 다른 차원보다 큰 정도 $\Delta$ | 억제 배율 $e^{-\Delta/0.04}$ |
|---|---|
| 0.02 | 0.61배 |
| 0.10 | **0.082배** (12배 억제) |
| 0.20 | 0.0067배 (150배) |
| 0.50 | $3.7\times10^{-6}$배 |

즉 sharpening이 쓰는 그 낮은 온도가 centering의 효과도 함께 키운다. 두 장치는 반대 방향으로 밀지만
**같은 $\tau_t$ 를 공유하는 하나의 식**이다.

## 2. 음의 피드백 루프 — 그리고 두 피드백의 시간상수 경쟁

### 루프의 형태

원-핫 붕괴는 **양의 피드백**이다. 차원 $i$ 가 조금 크면 → teacher 타깃 $q$ 가 $i$ 쪽으로 뾰족해지고
($\tau_t$ 가 낮아 더욱) → student가 $i$ 를 더 크게 내도록 학습되고 → EMA teacher도 따라가 $i$ 가 더 커진다.
승자독식이다.

centering은 정확히 그 반대 부호의 루프를 건다:

```
차원 i의 로짓이 계속 큼
      ↓  (배치 평균에 잡힘)
c_i 가 커짐  ←── EMA, 시간상수 1/(1-m) = 10 스텝
      ↓  (다음 스텝에서 z_i - c_i)
i가 e^{-c_i/τ} 로 억제됨
      ↓
i의 배치 평균이 작아짐 → c_i 가 다시 줄어듦
```

**"늘 큰 차원은 center도 크다"** — 이것이 상쇄의 전부다. 어떤 차원이 지배하려 할 때마다,
그 지배 자체가 자기를 누르는 힘의 크기를 결정한다.

### 측정 — center가 편향을 따라잡는 과정 (`expy.py` (a))

0번 차원에 고정 편향 $+4.0$ 을 걸어 두고 `update_center`만 반복했다. 지표는
**배치 평균 분포** $\bar q = \frac1B\sum_i q_i$ 의 최대 성분 (= "한 차원이 얼마나 지배하는가").

| 스텝 | $\bar q_{\max}$ | $h(\bar q)$ | $c_0$ | $\lVert\tilde c\rVert$ |
|---|---|---|---|---|
| 0 | **1.0000** | 0.0000 | 0.0000 | 0.0000 |
| 3 | 0.9961 | 0.0258 | 1.0773 | 1.0447 |
| 6 | 0.9891 | 0.0761 | 1.8631 | 1.8052 |
| 10 | 0.8015 | 1.0194 | 2.6042 | 2.5242 |
| 15 | 0.5003 | 2.0334 | 3.1810 | 3.0811 |
| 20 | 0.2608 | 2.5629 | 3.5195 | 3.4081 |
| 30 | 0.1064 | 2.7428 | 3.8390 | 3.7179 |
| 59 | **0.0824** | **2.7601** | 3.9967 | 3.8717 |

$1/K = 0.0625$, $\log K = 2.7726$. 시작 시점에는 **완전한 원-핫 지배**($\bar q_{\max} = 1$)였는데
60스텝 뒤 거의 균등해졌다. 네트워크는 전혀 학습하지 않았다 — 오직 center의 EMA 추적만으로 상쇄된 것이다.

$c_0$ 는 정확히 $4(1-0.9^t)$ 를 따라간다 ($t=10$: $4\times0.6513 = 2.605$ ✓).
반면 $\bar q_{\max}$ 는 **10~20스텝 사이에 급락**한다. 이유는 온도다: 남은 편향 $4-c_0$ 을
$\tau_t=0.04$ 로 나눈 값이 실제 로짓 격차이므로, $c_0=2.6$일 때 남은 $1.4/0.04 = 35$ 는 아직 압도적이고,
$c_0=3.5$ 에서 $0.5/0.04 = 12.5$ 가 샘플 간 변동 $0.5/0.04$ 와 같은 스케일이 되는 순간 분포가 흩어진다.

### 시간상수 경쟁 — 느린 center는 붕괴를 놓친다 (`expy.py` (c))

EMA의 시간상수는 $\tau_{\text{center}} = 1/(1-m)$ 스텝이다.

| $m$ | 0.5 | 0.9 | 0.99 | 0.999 |
|---|---|---|---|---|
| $1/(1-m)$ | 2 | **10** | 100 | 1000 |

붕괴 피드백의 시간상수는 학습률·모멘텀·헤드 크기가 정한다. **center가 그보다 느리면 못 따라잡는다.**
편향이 $b_t = 8(1-e^{-t/25})$ 로 자라는(즉 붕괴 시간상수 25스텝) 상황을 400스텝 굴렸다:

| $m$ | $\bar q_{\max}$ @50 | @150 | @399 | 결말 |
|---|---|---|---|---|
| 0.5 | 0.0984 | 0.0865 | **0.0882** | 즉시 억제 |
| **0.9** | 0.3878 | 0.0873 | **0.0834** | 잠깐 밀렸다 회복 |
| 0.99 | 1.0000 | 0.9909 | 0.1205 | 한참 지배당한 뒤 겨우 회복 |
| **0.999** | 1.0000 | 1.0000 | **1.0000** | **끝까지 못 따라잡음 = 붕괴** |

논문 Appendix D의 `Online centering` 표와 정확히 같은 결론이다:

| $m$ | 0 | 0.9 | 0.99 | 0.999 |
|---|---|---|---|---|
| ImageNet k-NN top-1 | 69.1 | **69.7** | 69.4 | **0.1** |

> "The convergence is robust to a wide range of smoothing, and the model only collapses
> when the update is too slow, i.e., $m = 0.999$."

`center_momentum = 0.9`가 EMA 모멘텀치고 **비교적 빠른** 값인 이유가 이것이다.
teacher EMA(`momentum_teacher = 0.996 → 1.0`)나 옵티마이저 모멘텀과 비교하면 눈에 띄게 작다.
center는 감시자이므로 감시 대상보다 빨라야 한다.

## 3. 시프트 불변성과의 구분 — **편차만이 작동한다** (핵심)

여기서 자연스러운 반문이 나온다.

> softmax는 모든 차원에 같은 상수를 더하거나 빼는 것에 불변이다:
> $$\mathrm{softmax}(z + a\mathbf 1) = \mathrm{softmax}(z)$$
> 그렇다면 center를 빼는 게 왜 효과가 있는가?

답: **center는 스칼라가 아니라 차원마다 다른 값을 가진 $K$차원 벡터**이기 때문이다.
center를 균일 성분과 편차로 쪼개면

$$c = \underbrace{\bar c\,\mathbf 1}_{\text{균일 — 아무 효과 없음}} + \underbrace{\tilde c}_{\text{편차 — 이것만 작동}}, \qquad \bar c = \tfrac1K\sum_i c_i,\ \ \sum_i \tilde c_i = 0$$

그러면 $\mathrm{softmax}((z-c)/\tau) = \mathrm{softmax}((z-\tilde c)/\tau)$ 다. 균일 성분은 통째로 소거된다.

### 실증 (`expy.py` (b))

(a)에서 학습된 center($\bar c = 0.2471$, $\lVert\tilde c\rVert = 3.8700$)로:

| 비교 | 최대 절대차 | 해석 |
|---|---|---|
| $q(c)$ vs $q(c + 137)$ | $8.98\times10^{-5}$ (float64에선 **0.0**) | 상수를 더해도 동일 — 시프트 불변 |
| $q(c)$ vs $q(c - \bar c)$ | $8.94\times10^{-7}$ | **편차만 남겨도 완전히 동일** |
| $q(c)$ vs $q(\bar c\,\mathbf 1)$ | **1.0** | 균일 성분만으론 전혀 다른 결과 |
| $q(\bar c\,\mathbf 1)$ vs $q(\mathbf 0)$ | $2.4\times10^{-19}$ | 균일 center = center 없음과 같음 |

(float32에서 $8.98\times10^{-5}$가 남는 건 $137/0.04 = 3425$ 를 `exp`에 넣은 반올림 오차다.
float64로 다시 하면 정확히 0이 된다. 실전에서 center의 절대 크기가 커지면 안 되는 실용적 이유이기도 하다.)

**결론: centering의 실효 자유도는 $K$ 가 아니라 $K-1$ 이다.** "센터가 크다/작다"는 무의미하고,
"센터의 차원 간 편차가 크다/작다"만이 의미를 갖는다. 그리고 이 사실이 곧바로 4절로 연결된다.

## 4. 왜 균등 붕괴는 못 막는가 — 사각지대

centering이 강제하는 것은 정확히 이것뿐이다:

> **어떤 차원도 배치 전체에서 전역적으로 우세하지 않게 한다.**

강제하지 **않는** 것:

> 각 샘플이 확신을 갖게 한다 / 서로 다른 입력이 서로 다른 출력을 내게 한다.

그래서 모든 샘플이 동일한 균등 분포를 내는 **균등 붕괴** 상태에 도달하면,
배치 평균이 이미 균등하므로 center의 편차 $\tilde c \to 0$ 이 되고, 3절에 의해 centering은 **항등연산**이 된다.

### 실증 (`expy.py` (d))

center를 일부러 $c_0 = 3.0$ 으로 데워 둔 뒤 (즉 편차노름 2.90에서 출발) 두 상황을 각각 200스텝 굴렸다.

| 스텝 | 원-핫 붕괴: $\lVert\tilde c\rVert$ / $h(\bar q)$ | 균등 붕괴: $\lVert\tilde c\rVert$ / $h(\bar q)$ |
|---|---|---|
| 0 | 2.9047 / 1.7267 | 2.9047 / 2.7081 |
| 10 | 3.5297 / 2.6499 | **1.0128** / 2.7081 |
| 30 | 3.8318 / 2.7340 | **0.1231** / 2.7196 |
| 60 | 3.8670 / 2.7534 | **0.0052** / 2.7721 |
| 199 | **3.8824** / 2.7613 | **0.0000** / **2.7726** |

- 원-핫 붕괴 쪽에서는 편차노름이 3.88까지 자라 강하게 작동한다.
- 균등 붕괴 쪽에서는 편차노름이 $2.0\times10^{-9}$ 로 죽는다. 수렴한 center는 정확히 영벡터다.
- 그 상태에서 **centering 적용 전후 분포 차이 = $3.7\times10^{-9}$** — 아무 일도 하지 않는다.

더 결정적인 것은 마지막 열이다. 수렴 후 $h(\bar q)$ 는 두 경우 모두 $\log K = 2.7726$ 이다
(원-핫 쪽 2.7613은 유한 배치의 표본 오차; 균등 쪽은 정확히 2.7726).
**배치 평균만 보면 두 붕괴가 구분되지 않는다.**
centering이 볼 수 있는 유일한 신호가 배치 평균인데, 배치 평균으로는 두 상태가 구분되지 않는다.
즉 centering은 균등 붕괴를 **막지 못하는 게 아니라 감지할 수단조차 없다.**

구분하려면 샘플별 엔트로피 $h(q_i)$ 를 봐야 하고, 그것을 낮추는 것이 sharpening($\tau_t$ 를 낮추기)의 일이다.
논문 §5.3이 교차엔트로피를 $H(q,p) = h(q) + D_{KL}(q\Vert p)$ 로 쪼개 보여주는 것이 정확히 이 대칭이다:
centering만 있으면 $h \to \log K$ (균등 붕괴), sharpening만 있으면 $h \to 0$ (원-핫 붕괴).

> **주의**: centering은 균등 붕괴를 "막지 못하는" 데서 그치지 않고 **적극적으로 그쪽으로 민다**
> (논문: *"centering prevents one dimension to dominate but encourages collapse to the uniform distribution"*).
> 형제 카드가 다루는 `center only` 실험(노트북 5절)이 그 결과를 수치로 보여준다.

## 5. 다른 배치 수준 제약들과의 위치

centering은 "배치 통계로 붕괴를 막는" 계열에서 **가장 약하고 가장 싼** 끝에 있다.

| 방법 | 제약의 형태 | 통계 차수 | 비용 | 배치 의존성 |
|---|---|---|---|---|
| **DINO centering** | 배치 평균의 EMA를 로짓에서 뺌 (소프트 바이어스) | 1차 | $O(BK)$, 1회 | **낮음** (EMA가 완충) |
| SwAV **Sinkhorn-Knopp** | 배치 내 균등 할당을 **최적수송으로 강제** | 행/열 주변분포 전체 | 반복 정규화 ($\sim$3회) | 높음 (배치 안에서 딱 맞춤) |
| batch-axis softmax | 배치 축으로 softmax (SK 1회 반복과 유사) | 1차 (하지만 하드) | $O(BK)$ | 높음 |
| Barlow Twins / VICReg | 상관·공분산 행렬을 항등에 가깝게 (중복 제거) | **2차** | $O(BD^2)$ | 중간 |
| BatchNorm (BYOL 논란) | 배치 평균 빼고 **표준편차로 나눔**, 네트 내부 | 1·2차 | 층마다 | 높음 |

**핵심 대비 — 하드 vs 소프트.**
Sinkhorn-Knopp은 "이 배치 안에서 각 프로토타입이 정확히 $B/K$ 개씩 가져가라"를 **등식 제약으로 푼다**.
centering은 "평균적으로 어느 차원도 튀지 말라"를 **바이어스 한 번으로 넌지시 민다**.
전자는 배치 하나로 균형을 맞추므로 배치가 작으면 제약 자체가 왜곡되고, 후자는 EMA가 여러 배치를 걸쳐
평균을 내므로 배치 크기에 둔감하다 — 논문이 **배치 8**로도 50에폭 35.2%를 얻은 근거가 이것이다 (§5.5).

**대가는 약함이다.** 논문 Table 15: momentum teacher가 없으면 centering만으로는 **0.1%** (완전 붕괴)이고,
SK 같은 더 강한 연산이 필요하다. momentum teacher가 있을 때만 centering으로 충분해진다 (76.1%).
반대로 momentum이 있으면 SK를 써도 별 이득이 없다. 즉 **centering의 약함은 momentum teacher의 관성이
이미 대부분의 안정화를 해 주고 있다는 전제 위에서만 감당 가능하다.**

**BatchNorm과의 차이.** 둘 다 배치 평균을 뺀다는 점은 같지만,
(1) centering은 분산으로 나누지 않는다 — 스케일 조절은 $\tau_t$ 가 따로 한다,
(2) 네트워크 내부가 아니라 **teacher 출력에만** 걸린다,
(3) `@torch.no_grad()`라 그래디언트가 흐르지 않는다 — BN처럼 미분 가능한 연산이 아니라 통계 추적이다,
(4) 그래서 학습/추론 모드 구분이 필요 없고, 추론 시엔 아예 존재하지 않는다.
DINO의 projection head가 BN을 안 써도 되는(§Appendix B, Table 14) 이유의 일부다.

## 6. `center_momentum`의 트레이드오프 (요약)

2절의 표가 전부다. 형제 카드에서 자세히 다루므로 여기선 요지만:

- **너무 크면(느리면)**: 붕괴 피드백을 못 따라잡는다 → $m=0.999$ 에서 k-NN 0.1.
- **너무 작으면(빠르면)**: center가 배치 노이즈를 그대로 받는다. `expy.py` (c)에서 $m=0.5$ 가 가장 빨리
  억제했지만, 실제 학습에서는 매 배치의 우연한 편중까지 타깃에 되먹여 타깃이 흔들린다.
  $m=0$ (배치 평균 그대로)도 69.1로 동작하긴 하지만 0.9보다 낮다.
- **배치 크기와의 관계**: EMA가 여러 배치를 평균하므로 유효 표본 수는 $\approx B/(1-m)$ 이다.
  배치가 작으면 $m$ 을 키워 보상할 수 있으나, 그러면 다시 추적 속도를 잃는다 — 이 절충이
  논문이 "작은 배치에서는 momentum rate 재튜닝이 필요할 것"이라 적은 이유다 (§5.5).

## 되짚기

| 질문 | 답 |
|---|---|
| 구체적으로 무엇을 하나? | teacher 로짓에서 배치 평균의 EMA $c$ 를 뺀다 (식 (4), $m=0.9$) |
| 확률 공간에서는? | 차원 $i$ 에 $e^{-c_i/\tau_t}$ 를 곱하고 재정규화 — 지수적·곱셈적 억제 |
| 왜 붕괴를 막나? | "늘 큰 차원 → 큰 $c_i$ → 강한 억제"라는 음의 피드백이 승자독식의 양의 피드백을 상쇄 |
| 실제로 작동하는 성분은? | center의 **차원 간 편차** $\tilde c$ 뿐. 균일 성분은 softmax 시프트 불변성으로 소거 |
| 막는 붕괴 | **원-핫 붕괴** (한 차원이 배치 전체를 지배) |
| 못 막는 붕괴 | **균등 붕괴** — 그 상태에선 $\tilde c \to 0$, centering은 항등연산 (배치 평균만으론 감지 불가) |
| 그래서 짝은? | sharpening (낮은 $\tau_t$). 둘은 같은 식에서 반대 방향으로 민다 |
| 실패 조건 | center가 붕괴보다 느릴 때 ($m=0.999$ → k-NN 0.1) |
