# DropPath에서 $1-p$ 로 나누는 이유

> 필요한 사전 지식은 딱 하나다: **확률과 통계의 이산확률변수 기대값**.
> $\mathbb{E}[X] = \sum_k x_k P(X = x_k)$ 와 $\mathbb{E}[aX] = a\,\mathbb{E}[X]$ 만 알면 이 카드는 끝난다.

---

## 0. 먼저 코드가 뭘 하는지

DINO의 `vision_transformer.py` 에 있는 함수다.

```python
def drop_path(x, drop_prob=0., training=False):
    if drop_prob == 0. or not training:
        return x                                      # ← eval 은 이 한 줄로 끝
    keep_prob = 1 - drop_prob
    shape = (x.shape[0],) + (1,) * (x.ndim - 1)       # (B, 1, 1) ← 샘플 단위 마스크
    random_tensor = keep_prob + torch.rand(shape, ...)
    random_tensor.floor_()                            # 0 또는 1 로 만듦
    output = x.div(keep_prob) * random_tensor         # ← 여기가 "1-p 로 나누기"
    return output
```

수식으로 쓰면 이게 전부다.

$$
\tilde{x}_i \;=\; \frac{x_i}{1-p}\cdot m_i,
\qquad m_i \sim \mathrm{Bernoulli}(1-p)
$$

Dropout은 텐서의 **원소 하나하나**를 끄지만, DropPath는 마스크 모양이 `(B,1,1)` 이라
**샘플 하나의 잔차 경로 전체**를 통째로 끈다. `Block.forward` 가

```python
x = x + self.drop_path(y)
```

이므로, $m_i = 0$ 이 된 샘플은 그 블록에서 $x \leftarrow x$, 즉 **항등 함수**가 된다.
그 샘플에게는 네트워크가 한 층 얇아진 셈이다. 이래서 이 기법의 이름이 **stochastic depth**(확률적 깊이)다.

질문은 이것이다: **왜 하필 $1-p$ 로 나누는가?** $2$ 로 나누거나, 아예 나누지 않으면 안 되는가?

---

## 1. 출발점: 베르누이 확률변수의 기대값

$m$ 은 값이 **0 아니면 1** 인 이산확률변수다. 정의상

$$
P(m = 1) = 1 - p, \qquad P(m = 0) = p
$$

여기서 $p$ 가 "끌 확률"(`drop_prob`)이고 $1-p$ 가 "살릴 확률"(`keep_prob`)이다.

기대값은 고교 정의 그대로 **값 $\times$ 확률의 합**이다.

$$
\mathbb{E}[m] \;=\; 1 \cdot (1-p) \;+\; 0 \cdot p \;=\; 1 - p
$$

이 한 줄이 이 카드의 씨앗이다. **베르누이 확률변수의 기대값은 성공 확률과 같다.**
직관적으로도 맞다 — 100번 시도해서 평균 $100(1-p)$ 번 켜지니, 한 번당 평균 $1-p$ 다.

$p = 0.1$ 이면 $\mathbb{E}[m] = 0.9$. 마스크를 곱하는 순간 **평균적으로 신호가 0.9배로 줄어든다**는 뜻이다.
이 "줄어듦"이 문제의 정체이고, $1-p$ 로 나누는 건 그걸 정확히 되돌리는 행위다.

---

## 2. 보정을 넣으면 기대값이 살아난다

$x_i$ 는 (그 순간엔) 그냥 정해진 숫자다. 확률적인 건 $m_i$ 하나뿐이다.
그래서 $\frac{x_i}{1-p}$ 는 **상수** $a$ 로 묶을 수 있다.

$$
\tilde{x}_i = a\,m_i, \qquad a = \frac{x_i}{1-p}
$$

기대값의 성질 $\mathbb{E}[aX] = a\,\mathbb{E}[X]$ (상수는 밖으로 빠진다)를 쓰면

$$
\mathbb{E}[\tilde{x}_i]
\;=\; \mathbb{E}\!\left[\frac{x_i}{1-p}\,m_i\right]
\;=\; \frac{x_i}{1-p}\,\mathbb{E}[m_i]
\;=\; \frac{x_i}{1-p}\,(1-p)
\;=\; x_i
$$

$1-p$ 가 **분모의 $1-p$ 와 약분되어 사라진다**. 이게 답이다.
$1-p$ 로 나누는 이유는, 마스크가 평균적으로 곱하는 값이 정확히 $1-p$ 이기 때문에
**미리 그 역수를 곱해 두면 평균이 원래 값 $x_i$ 로 되돌아오기** 때문이다.

정의로 직접 검산해도 같다 ($x_i = x$ 로 두고):

| $m$ | 확률 | $\tilde x$ 값 | 값 $\times$ 확률 |
|---|---|---|---|
| 1 | $1-p$ | $\dfrac{x}{1-p}$ | $x$ |
| 0 | $p$ | $0$ | $0$ |
| | | **합 = $\mathbb{E}[\tilde x]$** | $x$ |

주의할 점: 보존되는 건 **평균**이다. 개별 샘플은 절대 $x$ 를 받지 않는다.
$\frac{x}{1-p}$ (원래보다 큼) 아니면 $0$ 둘 중 하나다. 배치 전체로 평균이 맞는 것이다.

---

## 3. 보정을 빼면 무슨 일이 벌어지는가

만약 코드가 `x.div(keep_prob)` 없이 그냥 $\tilde x = x\,m$ 이었다면:

$$
\mathbb{E}[x\,m] = x\,\mathbb{E}[m] = x(1-p)
$$

**학습 때 이 블록이 내놓는 신호의 평균이 $x$ 가 아니라 $x(1-p)$** 다.
그런데 추론(`eval()`)에서는 마스크를 안 쓰니 그대로 $x$ 가 나온다.
학습에서 본 세계와 추론에서 보는 세계의 **통계가 다르다**. 모델은
"평균 $x(1-p)$ 짜리 입력"에 맞춰 뒷단 가중치를 학습했는데, 실전에서는 $\frac{1}{1-p}$ 배 큰 게 들어온다.

$x = 1$ 로 놓고 숫자로 보자.

| | $p = 0.5$ | $p = 0.1$ |
|---|---|---|
| $\mathbb{E}[m]$ (마스크 평균) | 0.5 | 0.9 |
| **보정 O**: 살아남은 값 $\frac{1}{1-p}$ | 2.000 | 1.111 |
| **보정 O**: 학습 시 평균 $\mathbb{E}[\tilde x]$ | **1.000** | **1.000** |
| **보정 X**: 살아남은 값 | 1.000 | 1.000 |
| **보정 X**: 학습 시 평균 | **0.500** | **0.900** |
| 추론 시 값 (`return x`) | 1.000 | 1.000 |
| 보정 X의 학습↔추론 불일치 배율 | **2.0배** | **1.11배** |

$p = 0.5$ 면 학습 때 평균 0.5 를 보고 추론 때 1.0 을 보니 **신호가 두 배로 뛴다**.
$p = 0.1$ 이라 작아 보여도 11% 어긋난다 — 그리고 §6에서 볼 텐데, 이게 12층 쌓이면 작지 않다.

워크스루의 실제 검증 코드도 정확히 이걸 확인한다 ($p=0.5$, 입력 전부 1, 배치 10만):

```
살아남은 샘플 비율 : 0.4996   (기대값 1-p = 0.5)
살아남은 값        : 2.0000   (= 1/(1-p))
전체 평균          : 1.0000   (원본 1.0 과 일치 → 기대값 보존 ✔)
eval 모드          : 원본과 동일? True
```

이론값 $1-p = 0.5$, $\frac{1}{1-p} = 2$, $\mathbb{E}[\tilde x] = 1$ 이 대수의 법칙대로 그대로 나온다.

## 4. 분산: 보정은 평균만 맞추고, 흔들림은 오히려 키운다

기대값만 보면 "완벽한 보정"처럼 보이지만, **분산은 전혀 보존되지 않는다.** 계산해 보자.

먼저 $m$ 의 분산. $m$ 은 0 또는 1 이라서 **$m^2 = m$** 이라는 편리한 성질이 있다 ($0^2=0$, $1^2=1$).
따라서 $\mathbb{E}[m^2] = \mathbb{E}[m] = 1-p$ 이고, 분산 공식 $\mathrm{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$ 에서

$$
\mathrm{Var}(m) = (1-p) - (1-p)^2 = (1-p)\big[1 - (1-p)\big] = p(1-p)
$$

이제 $\mathrm{Var}(aX) = a^2\mathrm{Var}(X)$ (상수는 **제곱**으로 빠진다)를 쓰면

$$
\mathrm{Var}(\tilde x)
= \left(\frac{x}{1-p}\right)^{\!2}\mathrm{Var}(m)
= \frac{x^2}{(1-p)^2}\,p(1-p)
= \boxed{\,x^2\,\frac{p}{1-p}\,}
$$

보정하지 않은 쪽은 $\mathrm{Var}(x\,m) = x^2 p(1-p)$ 다. 둘을 비교하면 성격이 정반대다.

| $p$ | 보정 O 분산 $\frac{p}{1-p}$ | 보정 O 표준편차 | 보정 X 분산 $p(1-p)$ |
|---|---|---|---|
| 0.0 | 0 | 0 | 0 |
| 0.1 | 0.111 | 0.333 | 0.09 |
| 0.2 | 0.250 | 0.500 | 0.16 |
| 0.3 | 0.429 | 0.655 | 0.21 |
| 0.5 | 1.000 | 1.000 | 0.25 |
| 0.9 | 9.000 | 3.000 | 0.09 |

보정 없는 분산은 $p = 0.5$ 에서 최대 0.25 를 찍고 다시 줄어든다 — 많이 끄면 그냥 다 0 이 되니 조용해진다.
반면 **보정한 분산은 $p \to 1$ 에서 발산한다.** 당연하다. 아주 드물게 살아남는 대신,
살아남을 때 $\frac{1}{1-p}$ 라는 거대한 값이 되니 진폭이 커진다.

**그런데 이 커진 분산이 버그가 아니라 기능이다.** 이게 DropPath의 정규화(regularization) 정체다.

- 평균이 맞아 있으니 모델은 **엉뚱한 스케일을 학습하지 않는다** — 편향(bias) 없음.
- 분산이 크니 매 스텝의 순전파/역전파에 **잡음이 섞인다** — 파라미터가 손실함수의 좁고 뾰족한 골짜기에 갇히기 어렵다.
- 어느 한 블록이 없으면 예측이 무너지는 구조를 못 만든다. 그 블록은 확률 $p$ 로 사라지므로,
  네트워크는 **여러 블록에 정보를 분산·중복**해서 담게 된다.

요약하면 DropPath는 "**편향 없는(unbiased) 잡음**"을 주입한다.
$1-p$ 로 나누는 것은 편향을 없애는 부분이고, 남은 분산이 정규화 효과다.
잡음의 세기는 위 표에서 보듯 $\frac{p}{1-p}$ 로, $p$ 를 올리면 급격히 세진다.

## 5. 이름의 유래: 왜 '역(inverted) dropout' 인가

원래 dropout(Srivastava et al., 2014)은 보정을 **반대편**에 두었다.

| | 학습(train) | 추론(eval) |
|---|---|---|
| **원조 dropout** | $\tilde x = x\,m$ (보정 없음) | $\tilde x = (1-p)\,x$ ← **여기서 곱함** |
| **inverted dropout** (현재 표준) | $\tilde x = \frac{x}{1-p}m$ ← **여기서 나눔** | $\tilde x = x$ (그대로) |

두 방식 모두 학습 시 평균과 추론 시 값을 일치시킨다. 원조는 "학습 평균 $x(1-p)$" 에 맞춰
**추론을 낮추고**, inverted는 "추론 값 $x$" 에 맞춰 **학습을 올린다**.
보정 위치를 학습 쪽으로 **뒤집었기(invert)** 때문에 inverted dropout 이라 부른다.

왜 뒤집는 게 이겼나 — 전부 실용적 이유다.

1. **추론 코드가 사라진다.** 배포·양자화·ONNX 내보내기에서 dropout 계열 모듈을 그냥 **떼어내면 끝**이다.
   원조 방식은 추론 그래프에 상수 곱셈이 계속 남아 있어야 하고, 그걸 빼먹으면 조용히 틀린 결과가 나온다.
2. **$p$ 가 층마다 다를 때 특히 중요하다.** DINO는 stochastic depth 확률을 깊이에 따라 선형으로 키운다.

   ```python
   dpr = [x.item() for x in torch.linspace(0, drop_path_rate, depth)]
   ```

   `drop_path_rate=0.1`, `depth=12` 면 블록별 $p$ 가 $0.000,\,0.009,\,0.018,\dots,\,0.100$ 로 전부 다르다.
   원조 방식이라면 추론 때 **블록마다 다른 12개의 보정 상수**를 기억해서 곱해야 한다. 관리 지옥이다.
   inverted는 각 블록이 자기 $p$ 로 학습 때 알아서 나눠 놓으니, 추론은 전 블록이 똑같이 항등이다.
3. **$p$ 를 학습 중에 바꿔도(스케줄링) 추론 코드가 안 흔들린다.**

## 6. 그래서 코드가 한 줄로 끝난다

$\mathbb{E}[\tilde x] = x$ 라는 §2의 결론이 곧바로 코드의 첫 줄이 된다.

```python
if drop_prob == 0. or not training:
    return x
```

- `not training` — `model.eval()` 상태. 학습 때 평균이 이미 $x$ 로 맞춰져 있으니 **보정할 게 없다**.
- `drop_prob == 0.` — $p=0$ 이면 $\frac{1}{1-p} = 1$, $m \equiv 1$ 이라 항등이다. 굳이 곱셈/난수 생성을 할 필요가 없다(연산 절약).

한술 더 떠서 DINO의 `Block` 은 아예 모듈조차 만들지 않는다.

```python
self.drop_path = DropPath(drop_path) if drop_path > 0. else nn.Identity()
```

`drop_path_rate=0.1` 인 `vit_tiny` 를 만들면 `blocks[0].drop_path` 는 `Identity`,
`blocks[11].drop_path` 는 `DropPath` 가 된다 (선형 램프의 첫 값이 정확히 0.0 이므로).

그리고 DINO는 이걸 **student 에만** 적용한다. teacher 는 EMA로 갱신되고 gradient가 흐르지 않으니
정규화할 대상 자체가 없고, 오히려 teacher 출력에 잡음을 넣으면 학습 타깃이 흔들려 해롭다.

## 7. residual 구조에서 왜 특히 치명적인가

ViT의 `Block` 은 pre-norm residual 이다.

$$
\begin{aligned}
x &\leftarrow x + \mathrm{DropPath}\big(\mathrm{MHSA}(\mathrm{LN}(x))\big)\\
x &\leftarrow x + \mathrm{DropPath}\big(\mathrm{Mlp}(\mathrm{LN}(x))\big)
\end{aligned}
$$

핵심은 **더하기가 층마다 누적된다**는 점이다. 한 블록의 잔차 기여가 평균적으로 어긋나면,
그 어긋남은 다음 블록의 입력이 되고, 그 블록의 기여를 또 어긋나게 만든다 — **복리처럼 곱해진다.**

간단한 장난감 계산을 해 보자. 잔차 가지의 크기가 대략 입력의 30% 라고 두면
($\lVert y\rVert \approx 0.3\lVert x\rVert$), 블록을 하나 지날 때 스케일은

- **보정 X 의 학습 시**: $1 + (1-p)(0.3)$ ← 평균적으로 잔차가 $(1-p)$ 배로 작게 들어옴
- **추론 시**: $1 + 0.3$ ← 잔차가 온전히 들어옴

$p = 0.1$ 이면 학습은 층당 $1.27$, 추론은 층당 $1.30$ 이다. 층당 2.4% 차이. 이걸 12층 쌓으면:

| 층 수 $L$ | 학습 스케일 $1.27^L$ | 추론 스케일 $1.30^L$ | 불일치 배율 |
|---|---|---|---|
| 1 | 1.27 | 1.30 | 1.02배 |
| 2 | 1.61 | 1.69 | 1.05배 |
| 4 | 2.60 | 2.86 | 1.10배 |
| 8 | 6.77 | 8.16 | 1.21배 |
| **12** | **17.61** | **23.30** | **1.32배** |

층당 2.4% 였던 어긋남이 마지막 층에서 **32%** 가 된다.
$1.024^{12} = 1.32$ — 지수함수의 위력이다. 만약 잔차가 아니라 순수 곱셈 스택이었다면 더 험하다:
층마다 $(1-p)$ 배씩 어긋나므로 12층 뒤엔 $0.9^{-12} = 3.54$, 즉 **3.5배**가 된다.

이 스케일 불일치가 실제로 만드는 사고들:

- **LayerNorm 통계 붕괴** — LN은 입력 분포를 정규화하지만 그 뒤 학습된 $\gamma, \beta$ 는
  학습 때 본 스케일에 맞춰져 있다. 입력 스케일이 다르면 그 보정도 어긋난다.
- **DINOHead 의 마지막 정규화** — 최종 특징을 $\ell_2$ 정규화하고 온도로 나눈 뒤 softmax를 태운다.
  들어오는 로짓 크기가 1.3배 달라지면 softmax 분포의 **뾰족함(sharpness)** 이 완전히 달라지고,
  DINO의 자기지도 학습은 이 분포 모양 자체가 학습 신호라 특히 민감하다.
- **깊을수록 나빠진다** — ViT-Base 는 12층이지만 더 깊은 모델일수록 지수가 커진다.
  게다가 stochastic depth 는 깊은 층에 더 큰 $p$ 를 주므로, 하필 누적이 가장 심한 뒷쪽에서 어긋남이 가장 크다.

$1-p$ 로 나누는 나눗셈 하나가 **모든 층에서 잔차 기여의 기대값을 정확히 $x$ 로 못 박아**,
이 지수적 누적을 애초에 발생시키지 않는다.

## 8. 한 장 정리

$$
\tilde x = \frac{x}{1-p}\,m,\quad m\sim\mathrm{Bernoulli}(1-p)
\;\Longrightarrow\;
\mathbb{E}[\tilde x] = x,\quad \mathrm{Var}(\tilde x) = x^2\frac{p}{1-p}
$$

| 질문 | 답 |
|---|---|
| 왜 $1-p$? | 마스크의 기대값이 정확히 $1-p$ 라서, 역수를 곱하면 약분되어 $\mathbb{E}[\tilde x]=x$ |
| 안 나누면? | 학습 평균 $x(1-p)$ vs 추론 $x$ → 학습/추론 통계 불일치, residual 12층에서 지수 누적 |
| 분산도 보존되나? | 아니다. $x^2\frac{p}{1-p}$ 로 **커진다**. 그 잡음이 곧 정규화 효과 |
| 왜 'inverted'? | 원조 dropout은 추론에서 $(1-p)$ 를 곱했는데, 그 보정을 학습 쪽으로 뒤집었다 |
| eval 코드? | `if drop_prob == 0. or not training: return x` — 보정 불필요, 한 줄로 끝 |

### 마지막 정직한 단서 두 개

1. **기대값 보존은 "그 블록 출력에 대해서만" 정확하다.** 뒤에 비선형(GELU, softmax)이 오면
   $\mathbb{E}[f(\tilde x)] \neq f(\mathbb{E}[\tilde x])$ 라서 최종 출력의 기대값까지 완벽히 보존되지는 않는다.
   그래도 편향을 층마다 없애 두는 게 아무 보정도 안 하는 것보다 압도적으로 낫다.
2. **개별 샘플은 절대 $x$ 를 못 받는다.** $\frac{x}{1-p}$ 아니면 $0$ 이다.
   "기대값 보존"은 배치·스텝 평균에 대한 진술이며, 그래서 배치가 아주 작으면 보정의 효과도 그만큼 거칠다.
